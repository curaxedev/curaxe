# UT-022 — Password dimenticata

## Descrizione

Flusso per richiedere il reset password e impostare una nuova password tramite link (mock email).

## Persona / Ruolo

**Utente con account password** (agenzia, struttura, admin)

## User stories

- Come utente B2B/admin dimentico la password e richiedo il link di reimpostazione
- Come utente apro il link e imposto una nuova password

## Wireframe descrittivo

```
+----------------------------------+
|  Password dimenticata            |
|  [Email]                         |
|  [Invia link]                    |
+----------------------------------+
        ↓
+----------------------------------+
|  Reimposta password              |
|  [Nuova password] [Conferma]     |
|  [Salva]                         |
+----------------------------------+
```

## Componenti UI richiesti

- `ForgotPasswordPage.tsx`
- `ResetPasswordPage.tsx`

## Stati

- **loading**: Invio richiesta / verifica token
- **error**: Email non trovata, account OTP-only, token scaduto
- **success**: Link generato (mock) / password aggiornata

## Validazioni e regole business

- Solo account con canale `password_totp`
- Password minimo 8 caratteri, conferma uguale
- Token monouso con scadenza 1h (mock sessionStorage)
