# UT-019 — Impostazioni account (tutte le persona)

## Descrizione

Sezione dashboard per modificare email, password (se applicabile) e preferenze notifiche.

## Persona / Ruolo

**Tutte le persona autenticate** (professionista, famiglia, agenzia, struttura, admin)

## User stories

- Come utente aggiorno l'email del mio account
- Come utente con password cambio la password
- Come utente configuro quali notifiche ricevere

## Wireframe descrittivo

```
+----------------------------------+
|  Impostazioni account            |
|  [Card Email]                    |
|  [Card Password / OTP notice]    |
|  [Card Notifiche toggles]        |
+----------------------------------+
```

## Componenti UI richiesti

- `AccountSettingsSection.tsx`
- `useAccountSettings.ts`

## Stati

- **loading**: Skeleton cards
- **error**: Retry + messaggi campo
- **success**: Banner conferma salvataggio

## Validazioni e regole business

- Email valida e non duplicata (mock)
- Password attuale corretta prima del cambio
- Account OTP: password non modificabile da UI
